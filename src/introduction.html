Private and public patches

Keep patches in your browser, or sign in with Google to save them to your account. Switch account patches between private and public whenever you choose.

Browse public patches

Browse rack previews, search by name, or see the most popular patches this week. Give someone else's patch a thumbs-up when you like it.

Copy patches

Save a copy to edit. Copies start private and credit the original creator.

Share a patch

Share a link to a public patch. It opens the latest saved version in the rack, with a name, description and rack preview for social posts.

03 / Code editor

Patch scripting

Use JavaScript to add modules, set controls and connect cables. Loops and functions let you repeat groups of modules and generate sequences.

Validate your code, check the connections, then select Apply to load it. Snapshot converts the current rack into editable code.

Read the patch scripting guide →

04 / WebMCP Experimental

Browser agents

A compatible browser agent can inspect your rack, discover module controls, write patch code and check connections. It can also apply a validated draft. The code is shown in the editor for you to inspect or edit.

Requires a supported browser and agent connection. You control playback, saving and publishing.
